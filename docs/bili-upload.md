FC27 存档编辑器：中文 Web 界面，直接改球员能力值和转会

## 简介

一个 EA SPORTS FC 27 Squads 存档编辑器，中文 Web 界面，本地运行、不联网。

主要功能：
· 球员编辑：搜索球员（支持中文名），直接改总评、潜力、位置、惯用脚、能力和身体数据
· 球队编辑：查看阵容，批量修改球衣号码
· 快捷转会 / 精确转会：选两支球队，点一下完成转会，含自由球员
· 国家队选拔：按国籍筛选，名单自动补满（男足 26 人 / 女足 23 人），号码一键分配
· 快捷功能：全员年龄调整、老将回巅峰、补齐缺失球员、添加缺失传奇
· Excel 导出：球员表或完整存档数据

安全性：所有修改先暂存在内存，确认后另存为新的 Squads 文件，原存档永远不会被覆盖，保存后还会自动重读校验。

技术栈：Python + Flask + 原生前端，命令行工具同源。原创代码 Apache-2.0 开源。
