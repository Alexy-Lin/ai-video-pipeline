# 视频封面设计与出图

EP03 成果：`out/cover-w.png`（4:3 横 1600×1200）、`out/cover-h.png`（3:4 纵 1200×1600）
组件：`src/excelcoverv2/index.tsx`（V1~V5 五套方案 + V4P 纵版）；旧版 `src/excelcover/index.tsx`
素材：`public/cover/table.png`（从录屏里裁的真实表格帧，1698×720）、`public/kf3/k04-dialog-filled.png`

## 一、先调研，别凭空设计

Figma Community / Dribbble 常有登录墙或人机验证（Dribbble 直接弹 Human Verification），**最有效的参考是同平台搜索结果页的封面墙**：
`https://search.bilibili.com/all?keyword=excel技巧` → 截图 → 肉眼归纳。

B 站 Excel 类封面的稳定套路（多条命中）：
1. **Excel 绿底 + 白粗字**是主流视觉锚点
2. 关键词用**黄/红高亮单字或单段**，不整句换色
3. 必须放**真实软件截图**，白边 + 投影 + 微旋转（像贴上去的一张纸）
4. 左上角**小胶囊标签**（系列名/集数，EP 编号对观众无意义，用「每天一个 Excel 小技巧」这种系列名）
5. 底部一条**结论/数据条**，让人 0.5 秒抓到价值

## 二、布局硬规则

- **主视觉必须是主题本身**：讲迷你图就让标题里出现「迷你图」，并让曲线穿字或紧贴标题（用户否掉过「一个格子看清一周」这种不点题的标题）
- 截图里**最关键的区域不能被裁**（EP03 第一版把「趋势」列裁掉了，等于废图）——出图后一定 `read_image` 自检
- 文字分栏给竖屏留安全区：横版字占左、图占右；纵版上字下图、底部信息带
- 三档信息层次：系列标签 → 大标题 + 副标 → 三步条 + 结论条 + 图例
- 图例写清颜色含义（红点=最高、蓝点=最低），封面自己会说话

## 三、出图（Remotion Still）

```powershell
cmd /c "npx remotion still src/excelcoverv2/index.tsx V4 out/cover-w.png --log=error"
cmd /c "npx remotion still src/excelcoverv2/index.tsx V4P out/cover-h.png --log=error"
```
一个文件里用多个 `<Composition>` 放多套方案，一次全部出图，再用 `read_image` 逐张查：
文字溢出、层叠遮挡、被裁的关键内容、底部被字幕/按钮压住。

**多次迭代的经验**：坐标式绝对定位很容易出现「绝对定位元素落在图片卡片下面/上面」的层叠问题，
每次改完必须重新出图看，不要只看代码。

## 四、方案对比与选型建议

- V1 截图为主：最稳，像正经教程封面
- V2 对比式（普通图表打红叉 vs 迷你图）：点击率最高，适合抖音信息流
- V3 曲线穿标题：设计感最强，一眼看出和折线有关
- V4 浅色极简：适合小红书（平台调性偏清新）
- V5 三卡流程：说服力最强，但手机端缩略图偏小

交付时给出 3–5 张方案 + 每个方案的一句适用场景，让用户挑，不要只给一张。

## 五、各平台要的尺寸别搞混（2026-10 实测）

| 平台 | 必填封面 | 实测尺寸 | EP03 出图 |
| --- | --- | --- | --- |
| B 站 | 1 张（必填，但上传层是拖拽式，ego 打不通） | 16:9 | `cover-w.png` 1600×1200 也能过（被裁） |
| 小红书 | 3:4 竖版 | 3:4 | `cover-h.png` 1200×1600 |
| 抖音 | **横封面 4:3 + 竖封面 3:4 两张都要** | 4:3 / 3:4 | `cover-w.png` + `cover-h.png` 正好对号 |

抖音特色：
- 进「设置竖封面」tab 时会 toast「已优先同步横封面底图和素材」，所以**先设横封面再设竖封面**，竖版能少调一次。
- 设好后「发文助手」会给**封面优化建议**，EP03 拿到的两条是：
  「横封面：封面边框面积过大」「竖封面：请勿使用截屏当封面」——**不阻塞发布**，但说明纯截图风在抖音算法侧偏弱，
  下一期可以试「截图卡片缩小 + 大面积纯色底 + 大标题」，别让截图铺满整张封面。

## 六、EP04 预测工作表：浅色版 + 片头成品图（2026-10-29 实测）

EP04 成果：`out/ep04-cover-169.png` 1920×1080 / `ep04-cover-43.png` 1600×1200 / `ep04-cover-34.png` 1200×1600（+ 同名 jpg）
源码：`src/coverep04/cover.tsx`（`Cover169B` / `Cover43` / `Cover34` 三个 Composition）

**交付顺序：先把「标题文稿」给用户定，再出图。** EP04 用户直接拍板主标题「预测工作表，一图帮你看未来」，
并明确说「不要再加太多文字」→ 整张封面只留三处文字：系列胶囊、主标题两行、副标「不用写公式」。

配色与底色：
- 第一版做了深色底，被否：「背景颜色太深了，用浅色好一点」→ 浅色方案成为默认。
- 浅色底：`linear-gradient(165deg,#FBFCFE,#F1F5FA 58%,#E9EFF7)` + 左上蓝光 / 右下橙光两层 radial；
  图表放进**白色圆角卡片**（`0 38px 90px rgba(17,32,50,.16)`），否则白底上没层次。
- 主标题第一行墨黑 `#0F1A26`、第二行橙 `#E2670E`。**白底上不要用 #FFD400**，几乎看不见（视频字幕可以）。

主视觉用「片头动画的成品帧」而不是 Excel 截屏：把 SVG 图表抽成组件直接渲染（蓝 24 个月历史线 + 橙预测线 + 橙色扇形 95% 区间 + 「今天」虚线）。
为了 360px 缩略图也能看到「未来」那一段：
- 扇形本身再叠一层**同形状**的模糊光晕（`<polygon filter=blur>`），橙色预测线也描一层模糊；
- **不要用矩形径向光晕**，它在白卡上会留下硬边；
- 置信区间填充 0.20、虚线边界透明度 0.9。

版式：16:9 字在上、图铺满；4:3 字在上、图居中；**3:4 用「图上字下」**，标题放大到 138px——否则竖版下半个版面是空的。

出图与自检：
```powershell
# Remotion 4.0.538：npx.ps1 被执行策略挡，直调 CLI
node "node_modules/@remotion/cli/remotion-cli.js" still "src/coverep04/cover.tsx" Cover169B "out/ep04-cover-169.png" "--browser-executable=C:\Program Files\Google\Chrome\Application\chrome.exe" "--log=error"
# 缩略图可读性自检
& $ff -i out/ep04-cover-169.png -vf "scale=360:-1" out/cov4/preview-360.png
```
**每张图出完必须 `read_image` 看**：EP04 第一轮就是靠看图发现「右侧最后一个刻度 2025-06 被裁」「竖版底部空一大块」。
另外注意：用 PowerShell `Get-Content -Raw | -replace | Set-Content` 改含中文的 tsx 会把编码搞坏（后续 read 报 invalid UTF-8），
一律用文件编辑工具写回。
