# Excel 技巧视频 · 制作规范（长期有效）

## 一、镜头运动

- **禁止**整体画面缓慢放大 / 缓慢推拉（看着头晕，信息飘）。
- 需要强调某个点时，用**快速缩放**：约 6–8 帧（0.2–0.27s）缩放到 1.6–2.0 倍，停留，再用 6–8 帧回到原比例。
- 一次只缩放一个焦点（对话框、某个按钮、某列结果），不要连续漂移。
- 回到原比例后至少停 0.5 秒再切下一步，避免来回晃。

## 二、步骤完整性

- 每个视频必须完整走完操作链路，不允许跳步：
  1. 选中数据
  2. 点「插入」
  3. 点「迷你图 → 折线」
  4. 对话框填位置 → 确定
  5. **下拉填充**（不能直接给成品）
  6. **勾选高点 / 低点**
- 每个状态都要有对应的真实截图，不能用一个"完成态"截图糊弄中间步骤。
- 截图顺序 = 视频顺序，状态之间要有可见差异（选中、对话框、单行、多行、标点）。

## 三、画面真实性

- 界面像素一律来自真实 Excel 截图（2x 采集），不用手绘 UI。
- 只有光标、点击波纹、悬停高亮、输入文字、缩放这些"动作层"是代码生成的。
- 光标移动要有人味：缓动 + 到位后微停 0.15s 再点击。

## 四、版式

- 横屏 1920×1080：左侧 260px 信息栏（期号 / 标题 / 步骤进度），主画面 1478×850，底部字幕。
- 字幕：黄字黑边，每屏 ≤ 16 字，一行。
- 步骤条要随进度打勾，最后一步完成后全部打勾。

## 五、其他

- 音频以真人口播为准，时间轴按实际语速重排。
- 结论条只在结论句出现时出现，不要常驻。
