### 2.1 标题模式（可直接抄结构）

- **否定日常动作**：Stop Doing Extra Work / Stop Scrolling / Stop Copy-Pasting
- **内行口吻**：Almost Nobody Knows / Hidden Features / The Tricks I Wish I Learned Years Ago
- **具体结果压过术语**：章节名是「Find mismatched numbers instantly」「Move columns with one drag」「ONE CELL TWO HEADINGS」（缩略图上直接写这句），而不是「零轴」「净达成率」
- 数据点：**标题具体到「一个动作 + 一个结果」的视频，播放明显更高**

### 2.2 竖屏（Shorts）侧的残酷事实

## 4. EP04 三个方案（按推荐顺序，可直接开拍）

### 方案 A（首推）：预测工作表

- **标题候选**：「Excel 自己算出未来 12 个月」「老板要全年预测，Excel 30 秒给你」「不用公式，Excel 一键预测」
- **0–3 秒钩子**：直接甩成品——历史数据实线 + 未来 12 个月虚线 + 灰色置信区间（不要先展示表格）
- **三步**：选中「日期 + 数值」两列 → 数据 → 预测工作表 → 创建（自动生成新表和预测图）
- **时长**：35–40s
- **视觉点**：虚线未来段 + 置信区间自动出现；可以做一个「改一个历史值 → 预测线跟着动」的收尾镜头
- **录制准备**：造 24 个月连续日期 + 带轻微季节性波动的销量；Excel 365 本机已确认有「预测工作表」命令（`CommandBars` 探测到「预测工作表(&F)」）
- **风险**：Office 2016+ 才有（WPS 不确定）→ 标题/简介注明「Excel 2016 及以上」，评论区置顶版本说明
- **为何选它**：B站没有 ≤3 分钟的专门视频，等于没人占位；YouTube 上这个功能单独就能拿 99 万播放

### 方案 B（次推）：链接的图片（照相机）

- **标题候选**：「Excel 截的图会自己变」「改数字，图跟着变，同事以为我装了插件」「截图还能实时更新？」
- **0–3 秒钩子**：左边源表改一个数 → 右边「图片」里的同一个格子跟着变
- **三步**：复制表格区域 → 选择性粘贴 → 链接的图片（或把「照相机」加到快速访问工具栏）→ 改源数据演示联动
- **时长**：35s
- **版本**：全版本可用，零函数
- **和 EP03 的关系**：与迷你图同属「单元格内可视化」，可做成系列承接；旧的是 7 分半长视频，竖屏 35s 是新的

### 方案 C（三推）：Ctrl+\ 两表找不同

- **标题候选**：「两张表哪里不一样？按一下 Ctrl+\，不同的格子全变红」「核对两表不用 VLOOKUP」
- **0–3 秒钩子**：两张几乎一样的表并排 → 按 Ctrl+\ → 差异格瞬间全红
- **三步**：两表并排同区域 → 选中 → Ctrl+\ → 填充红色（老版本走 定位条件→行内容差异）
- **时长**：30s（最快的完播型）
- **风险**：「找不同」是 B站红海需求（3.6万/7482），优势在**快捷键做法**（专门供给 1116），标题要突出「一下」而不是「找不同教程」

## 5. 包装：从 YouTube 爆款反推的 5 条硬要求

1. **标题只写结果 + 场景**，不写术语。「零轴+负值可视化」→「迷你图一列数字变趋势」。
2. **前 3 秒给成品**，不给表格。你们 EP03 第 3 秒还在展示表格，第一句是「大家可以看到上面这个图」。
3. **封面 = 具体界面反差**：两表变红 / 预测虚线 / 图片自动变，配 4–6 个大字。
4. **简介别留「-」**：3 行关键词 + 一句结论（EP03 简介是空的，搜索和推荐拿不到词）。
5. **竖屏单独出母版**：表格铺满宽度（EP03 上下大片黑边，Excel 只占中间一条）。

## 6. 方法、限制、数据文件

- **YouTube**：搜索页 + 7 条视频的简介/章节（按要求未播放视频）；播放量为页面公开数，页面语种为中文（万/次观看）。
