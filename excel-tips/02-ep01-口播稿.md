# EP01 · 勾选即追踪（口播稿 + 分镜）

目标时长：60 秒（竖屏 1080×1920 / 30fps）
演示场景：10 条任务清单（A 任务 / B 负责人 / C 复选框控件 / D 链接列，隐藏）

数据约定：初始已勾 2 条 = 20%；每勾一条 +10%。

---

## 一、标题（三选一，发布时做 A/B）

1. 勾一下，整行自动变灰，进度条自己涨
2. 同事以为我写了代码，其实我只点了「插入复选框」
3. 别再手动数完成了几条，让表格自己算

**封面**：大字「勾一下 = 全自动」+ 一张勾选后整行变灰的截图

## 二、口播稿（约 300 字 / 60 秒）

> 加粗 = 重音；/ = 停顿；语气按口语，别念标点。

**（0:00–0:03 钩子｜直接演示结果）**
看到没？/ 我只是勾了这一个框——整行**自动**变灰，上面这个进度条，**自己**涨了 10%。

**（0:03–0:10 痛点）**
以前做完一条，你得手动改颜色、手动数完成了几条。改到第三遍，/ 真的想删表。

**（0:10–0:23 第一步）**
三步。第一步，插入复选框。/ Office 365 直接点「插入」→「复选框」；2016 和 WPS 用「开发工具」→「插入」→「复选框」。右键，设置控件格式，单元格链接选**右边这一格**，再把这一列藏起来。

**（0:23–0:35 第二步）**
第二步，条件格式。选中这三列，新建规则，选「使用公式」，输入 **=$D2=TRUE**，格式设成灰字、浅灰底。确定。/ 现在勾一下试试。

**（0:35–0:47 第三步）**
第三步，让进度条自己算。完成数用 **COUNTIF(D:D,TRUE)**，总数用 **COUNTA(A:A) 减一**，两个一除就是百分比，单元格再套上数据条。

**（0:47–0:56 效果）**
勾一个，进度条涨一点；取消勾选，颜色**自己**恢复。整张表，你只需要勾。

**（0:56–1:00 收尾）**
学会这招，汇报时不用再临时数数。关注我，每天一个让表格自己干活的技巧。

## 四、录音提示

- 环境：安静房间，手机或麦克风靠近嘴 15cm，避开空调和键盘声
- 一句一录：每句之间停 0.5 秒，方便我按句对齐、挑最好的版本
- 语速：比平时聊天稍快一点点，钩子那句（0:00–0:03）再快 10%
- 数字要读清楚：「10%」「=$D2=TRUE」「COUNTIF」这些是观众会暂停看的点
- 别念「分号」「括号」，直接读内容；公式那几句可以放慢

> 你把录音丢给我（wav/m4a 都行），我做降噪 + −16 LUFS 标准化 + whisper 词级时间戳，
> 然后按你的实际语速重排分镜，再进 Excel 自动录制。

## 五、版本说明（置顶评论备用）

- **Microsoft 365**：插入 → 复选框（一键）
- **Office 2016 / 2019 / 2021**：文件 → 选项 → 自定义功能区 → 勾选「开发工具」→ 开发工具 → 插入 → 窗体控件 → 复选框
- **WPS**：插入 → 复选框（部分版本叫「表单控件」）
- 条件格式、COUNTIF、数据条：**所有版本通用**
